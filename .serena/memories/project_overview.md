# Project Overview

## Purpose
This is a numerical error visualization project using Streamlit to create an educational web application. The goal is to help users understand how floating-point arithmetic errors occur in computer calculations by visualizing the step-by-step process of decimal to binary conversion and the inherent precision limitations.

## Tech Stack
- **Python** - Main programming language
- **Streamlit** - Web framework for creating the interactive application
- **Pandas** - Data manipulation (already in requirements)
- **Plotly** - For interactive visualizations (to be added)

## Project Structure
- `streamlit_app.py` - Main Streamlit application file (currently minimal)
- `requirements.txt` - Python dependencies
- `README.md` - Project description (minimal)
- `.devcontainer/` - Development container configuration
- `.serena/` - Serena MCP server configuration
- `.claude/` - Claude Code configuration

## Current State
The project is in early stage with basic Streamlit setup and minimal dependencies. The main application file exists but contains only basic Streamlit import.
